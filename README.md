# Preguntas y Respuestas

Juego web interactivo de preguntas y respuestas sobre fútbol argentino.

## Descripción
Este proyecto permite a los usuarios elegir su equipo favorito, seleccionar la dificultad y responder preguntas tipo quiz. Al finalizar, pueden compartir su puntaje personalizado por WhatsApp y desafiar a sus amigos.

## Tecnologías utilizadas
- **HTML5**: Estructura de la página y formulario.
- **CSS3**: Diseño moderno, responsivo y estilos personalizados.
- **JavaScript (ES6+)**: Lógica del juego, validaciones, manipulación del DOM y POO.
- **Meta tags**: SEO y redes sociales (Open Graph, Twitter).

## Características
- Validación de formulario antes de iniciar el juego.
- Puntaje mostrado como "X de Y puntos".
- Compartir puntaje por WhatsApp con mensaje personalizado y equipo elegido.
- Diseño 100% responsive, con imágenes decorativas solo en escritorio.

## Instalación y uso
1. Clona el repositorio:
   ```bash
   git clone https://github.com/Miguelgonzalezfofe/PreguntasYRespuestas.git
   ```
2. Abre el archivo `index.html` en tu navegador.
3. Completa el formulario, selecciona tu equipo y dificultad, y comienza a jugar.
4. Al finalizar, comparte tu puntaje por WhatsApp.

## Estructura del proyecto
- `index.html`: Página principal y formulario.
- `styles.css`: Estilos y responsividad.
- `script.js`: Lógica del juego y validaciones.
- `questions.js`: Preguntas por equipo (debes personalizar este archivo).
- `README.md`: Documentación del proyecto.

## Personalización
- Puedes agregar o modificar preguntas en `questions.js`.
- Cambia las imágenes decorativas en la carpeta `img` (`izquierda.png` y `derecha.png`).
- Edita los estilos en `styles.css` para adaptar el diseño a tu preferencia.
